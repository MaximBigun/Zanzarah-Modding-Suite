NPC предмет нападение дикой феи
ЛКМ + движение — вращение, колесо — масштаб. Стрелки — перемещение по карте, Shift+стрелка — быстрее. Num 7/9 — поворот камеры влево/вправо, Num 8/2 — камера вверх/вниз. Клик по метке выбирает объект. Розовая область показывает радиус нападения дикой феи.

Позиция
0 = обычный NPC без автозапуска боя. Для hostile-trigger в оригинальных SCN радиус хранится как float у Trigger type=1.
Команда фей этого NPC

Команда хранится в _fb0x05. Если NPC используется в нескольких местах, изменение затронет все его размещения.

Количество создаёт несколько настоящих collectable-объектов в одной точке. Например, «Средний бальзам ×3» даст три экземпляра при подборе. Список ограничен предметами, для которых в оригинальном data_0.pak найдена физическая модель ITMxxx.DFF.

Место нападения

ii4 — индекс encounter-пула (0–33), а не ID одной феи. Все 34 пула расшифрованы статически из zanthp.exe: показываются точный состав, вес выбора каждого вида и вычисляемый диапазон уровней. ii3 похож на шанс срабатывания, float-параметр — на радиус. «Режим (raw)» пока не расшифрован и сохраняется при редактировании.

Экспериментальный патч EXE. Он оставляет оригинальные Pool 0–33 без изменений и добавляет новые Pool 34–45. Всегда сохраняйте оригинальный zanthp.exe.

EXE ещё не выбран.
Кастомный encounter-пул

Вес — это число одинаковых слотов выбора. Сумма весов не может быть больше 8. Например веса 4 / 2 / 2 дают вероятности 50% / 25% / 25%.

После скачивания: сделайте резервную копию оригинального zanthp.exe, замените его пропатченной копией и в SCN назначьте точке Pool 34–45. Старые 0–33 продолжают работать как раньше.

Диагностика




Редактор работает локально. Перед заменой игровых файлов сохраняйте резервную копию оригинала.
