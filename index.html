Выберите внешность, реплику нападения и команду фей. Затем поставьте готового врага одним кликом.

Реплика при нападении

Используются только существующие игровые реплики. Кастомный текст отключён: игровой тест показал вылет при нападении с созданной вручную записью диалога.

Боевые скрипты всегда берутся из проверенного рабочего шаблона nq4001, а команда C.<model> заменяется на выбранную внешность.
Групповое нападение

v0.9.0: подтверждённая в игре схема группового боя. Лидер остаётся battle-ready nq4001, помощники создаются по профилю ns321a (ii=3 / ii2=3) и связываются через P.<marker>.<UID> + отдельный ii=5 marker.

v0.9.0: групповая механика подтверждена в игре с одним и двумя помощниками. Для каждого support используется P.<marker>.<UID> + Q.10; лишние фиксированные фазы &.3001 / &.3002 / &.3003 удалены — именно после этого исчезли три телепортации камеры перед боем. Post-battle cleanup генерирует a.<trigger> для каждого support, поэтому вся группа исчезает после победы. 3D-перетаскивание по BSP сохранено.

Количество создаёт несколько настоящих collectable-объектов в одной точке. Например, «Средний бальзам ×3» даст три экземпляра при подборе. Все новые предметы автоматически создаются на +1.0 по Y относительно выбранной точки, чтобы не застревать в земле. Список ограничен предметами, для которых в оригинальном data_0.pak найдена физическая модель ITMxxx.DFF.

Место нападения

В режиме «Одна конкретная фея» редактор автоматически создаёт или повторно использует Pool 34–255 с вероятностью 100% для выбранной феи. Для такого объекта нужен пропатченный zanthp.exe из вкладки «Пулы». ii3 похож на шанс срабатывания, float-параметр — на радиус. «Режим (raw)» пока не расшифрован и сохраняется при редактировании.

Экспериментальный патч EXE. Он оставляет оригинальные Pool 0–33 без изменений и добавляет новые Pool 34–255. Всегда сохраняйте оригинальный zanthp.exe.

Кастомный encounter-пул

Вес — это число одинаковых слотов выбора. Сумма весов не может быть больше 8. Например веса 4 / 2 / 2 дают вероятности 50% / 25% / 25%.

После скачивания: сделайте резервную копию оригинального zanthp.exe, замените его пропатченной копией и в SCN назначьте точке Pool 34–255. Старые 0–33 продолжают работать как раньше.

Диагностика




Редактор работает локально. Перед заменой игровых файлов сохраняйте резервную копию оригинала.
