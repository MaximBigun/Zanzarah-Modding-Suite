Zanzarah Enemy Editor v0.2

Новое в v0.2:
- реальная 3D-геометрия уровней из RenderWare BSP;
- автоматическое чтение нужного WORLDS/SC_xxxx.BSP прямо из оригинального data_0.pak;
- отдельные BSP тоже поддерживаются;
- NPC отображаются поверх геометрии по реальным X/Y/Z;
- вращение камеры мышью, масштаб колесом, сброс камеры.

Запуск:
1. Откройте index.html в Chrome/Edge.
2. Нажмите «Открыть папку игры».
3. Выберите папку достаточно высокого уровня, содержащую SCN/_fb0x05.fbs и, желательно, data_0.pak.
4. Выберите сцену слева.

Если data_0.pak присутствует в выбранном дереве файлов, редактор читает только нужный кусок PAK для текущей сцены; распаковывать 774 МБ целиком не требуется.

Управление 3D:
- зажать левую кнопку мыши и двигать: вращение;
- колесо: приблизить/отдалить;
- «Сбросить камеру»: показать сцену целиком;
- клик по голубой метке NPC: выбрать мастера.

Важно: v0.2 показывает геометрию и vertex colors. Игровые текстуры/DFF-модели пока не подключены — это следующий слой визуализации.
Перед заменой файлов игры делайте резервные копии.
