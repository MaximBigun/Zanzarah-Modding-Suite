Zanzarah World Editor v0.4

Что нового:
- отдельная кнопка выбора data_0.pak — BSP больше не обязан лежать рядом со SCN;
- точная диагностика, почему BSP не загружен;
- режим «Дикие феи»: отображение, добавление кликом/по координатам, изменение и удаление зон нападения;
- для зон диких фей: выбор феи, шанс, радиус и raw-режим;
- кнопка «↶ Назад» отменяет последнее ДОБАВЛЕНИЕ NPC, предмета или зоны дикой феи на текущую сцену;
- Ctrl+Z делает то же самое, если фокус не находится в поле ввода.

Запуск:
1. Распакуйте архив.
2. Откройте index.html в Chrome или Edge.
3. Нажмите «Открыть папку игры» и выберите папку, где доступны _fb0x05.fbs и SCN.
4. Если data_0.pak не находится в этой папке/подпапках, нажмите «Выбрать data_0.pak» и укажите его отдельно.

Важно:
- «Назад» отменяет именно операции добавления. Редактирование и удаление пока не входят в историю Undo.
- История Undo сбрасывается при повторном открытии сцены.
- Всегда храните резервные копии оригинальных игровых файлов.


v0.4.1 — исправление BSP для сцен md_*
- BSP теперь ищется по внутреннему полю [Misc] -> sceneFile, а не только по имени SCN.
- Пример: md_Doommine.scn -> sceneFile md_0004 -> RESOURCES\WORLDS\MD_0004.BSP.
- Имя SCN остаётся запасным вариантом для обычных сцен.
- Поиск отдельного BSP стал регистронезависимым.


v0.4.2 — исправление 3D BSP:
- исправлена ошибка `overlay is not defined` в Viewer;
- исправлены смещения World Struct (worldSectors/format);
- RenderWare version больше не захардкожена на 0x304; поддержан 0x310 у md_* BSP;
- проверено на SC_0231.BSP и MD_0004.BSP, извлечённых из пользовательского data_0.pak.


ДИКИЕ ФЕИ v0.7.0
-----------------
Encounter pool хранится в Trigger.ii4 (0..33). Полный состав пулов извлечён из zanthp.exe, функция 0x00476102. Повтор одного ID в raw slots повышает вероятность выбора. Диапазон уровня вычисляется из levelParam тем же алгоритмом, который используется игрой.


КАСТОМНЫЕ ПУЛЫ v0.8.0 EXP
-------------------------
Вкладка «Пулы» умеет создавать новые encounter-пулы ID 34..255 без замены оригинальных 0..33.

Как использовать:
1. На вкладке «Пулы» выберите оригинальный zanthp.exe.
2. Выберите Pool 34..255 и включите «Активировать этот пул».
3. Укажите фей и веса. Сумма весов максимум 8. Вес = число raw slots, поэтому 4/2/2 означает 50%/25%/25%.
4. Укажите levelParam M. Редактор показывает диапазон уровней, который из него получает оригинальный алгоритм игры.
5. Нажмите «Запомнить настройки пула».
6. Нажмите «Скачать zanthp_custom.exe».
7. Сохраните резервную копию оригинального zanthp.exe и замените его скачанным файлом (переименовав в zanthp.exe).
8. В «Дикие феи» назначьте точке активированный Pool 34..255 и сохраните SCN.

Оригинальные Pool 0..33 патчер не переписывает. Патч рассчитан на предоставленный zanthp.exe размером 2 170 880 байт и откажется патчить неизвестную версию.

v0.8.1 EXP — уровень кастомных пулов и NumPad-камера
- В Custom Pool 34–255 теперь выбирается понятный диапазон уровня; технический levelParam скрыт.
- Диапазон использует оригинальную формулу генерации уровня Zanzarah.
- NumPad 7/9: поворот камеры влево/вправо.
- NumPad 8/2: поднять/опустить камеру.


v0.8.2 EXP — количество предметов
- Во вкладке «Предметы» добавлено поле «Количество при добавлении» (1..99).
- При количестве N редактор создаёт N отдельных collectable-объектов в одной координате. Это сохраняет оригинальную механику предметов и позволяет, например, положить 3 средних бальзама в одной точке.
- Одно действие добавления сохраняется как один шаг Undo.


v0.8.3 EXP — Custom Shadow Elf:
- Оригинальный _ShadowElf защищён от изменения команды.
- Выберите _ShadowElf, задайте до 5 фей и нажмите «Создать Custom Shadow Elf».
- Редактор добавит новую независимую запись _CustomShadowElf_XX в _fb0x05.fbs с отдельным UID и фиксированными W-командами.
- После установки на карту скачайте и замените одновременно _fb0x05.fbs и изменённую SCN.


v0.8.4 EXP — одиночные дикие феи
----------------------------------
Во вкладке «Дикие феи» теперь можно выбрать «Одну конкретную фею». Редактор сам создаёт или повторно использует Custom Pool 34–255 с вероятностью 100% для выбранного вида и выбранным диапазоном уровня. Одинаковые вид+уровни повторно используют тот же пул. После таких изменений нужно скачать актуальный zanthp_custom.exe во вкладке «Пулы».


v0.8.5 EXP — расширенные Custom Pools
- Диапазон кастомных encounter-пулов расширен с 34–45 до 34–255.
- Доступно 222 кастомных ID поверх оригинальных 0–33.
- EXE-патч переведён на компактный generic dispatcher v2: один обработчик читает конфигурацию пула из таблицы, поэтому больше не нужен отдельный code stub для каждого пула.
- Патч v2 умеет читать/подхватывать настройки старого Custom Pools v1 (34–45) при открытии ранее пропатченного EXE.
- Режим «Одна конкретная фея» автоматически использует весь диапазон 34–255.


v0.8.6 EXP — исправления gameplay-тестов
- Исправлена схема создания Custom Shadow Elf после теста, где вместо эльфа отображалась W-фея.
- Новые предметы автоматически создаются на Y +1.0.
- Количество предметов подтверждено в игре на монетах и кристаллах; остальные предметы ещё тестируются.


v0.8.7 EXP — Custom Shadow Elf gameplay fix #2
- Gameplay-тест v0.8.6 показал: Custom Shadow Elf мог полностью отсутствовать в игре.
- ns322a больше не используется как база: его сюжетные Script1/Script4 могут деактивировать actor.
- Новый безопасный шаблон — ns321a: реально размещён в sc_0611.scn, использует тот же Shadow Elf actor ref 0x97688F91 и минимальные скрипты.
- Для Custom Shadow Elf Script2 принудительно использует C.u002s02m + пользовательские W.*.
- При размещении воспроизводится trigger profile оригинального ns321a: ii=3, ii2=3, ii3=0, ii4=0.
- Scene.s для нового Custom Shadow Elf оставляется пустым, как у большинства оригинальных NPC.
- hostile radius по умолчанию остаётся 5.0.
- Требуется новый gameplay-тест.
