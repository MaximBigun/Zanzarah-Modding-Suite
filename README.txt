Zanzarah World Editor v0.3
==========================

Что умеет
---------
- Читать _fb0x05.fbs и редактировать команды мастеров фей (W.<fairy>.<slot>.<level>).
- Читать SCN и находить NPC через Scene -> Trigger -> UID.
- Читать data_0.pak без предварительной распаковки и загружать BSP выбранной сцены.
- Показывать настоящую BSP-геометрию уровня в 3D.
- Показывать NPC (голубые круги) и собираемые предметы (зелёные квадраты).
- Добавлять NPC кликом по поверхности BSP.
- Находить точную X/Y/Z точки клика пересечением луча с треугольниками BSP.
- Показывать существующие collectable-предметы из Models_v3 + Behaviours.
- Добавлять, перемещать, менять тип и удалять предметы.
- Быстрые предметы: деньги эльфов, лекарственные травы, серебряный/золотой/хрустальный шары, мана.
- Сохранять изменённую SCN и _fb0x05.fbs.

Запуск
------
1. Распакуйте архив редактора.
2. Откройте index.html в Chrome/Edge.
3. Нажмите «Открыть папку игры» и выберите достаточно высокую папку, чтобы браузер увидел _fb0x05.fbs, SCN и data_0.pak.
4. Выберите сцену слева.
5. Для установки предмета выберите его во вкладке «Предметы», нажмите «+ Предмет кликом» и щёлкните по видимой поверхности BSP.
6. Нажмите «Скачать текущую SCN» и заменяйте игровой файл только после резервной копии.

Как кодируется предмет
----------------------
Редактор использует схему, обнаруженную в оригинальных сценах:
- Models_v3: модель ITMxxx и мировые координаты;
- Behaviours: 1000/1001/1002 = collectable;
- Scene: ссылка на индекс модели (type 3).
Новая запись создаётся с behaviour 1000, который в оригинальных сценах используется для всех основных собираемых предметов, включая деньги, травы и сферы.

Ограничения v0.3
----------------
- BSP уже настоящая, но оригинальные DDS/BMP-текстуры мира пока не накладываются.
- DFF-модели предметов пока отображаются маркерами, а не собственной 3D-геометрией.
- В список добавления включены только Item ID, для которых в предоставленном оригинальном data_0.pak найдена соответствующая модель ITMxxx.DFF.
- Неизвестные itmXXX/itmYYY/itmZZZ существующих сцен показываются, но редактор не предлагает их как новый тип, пока их игровая семантика не подтверждена.

Всегда сохраняйте резервные копии игровых файлов.
