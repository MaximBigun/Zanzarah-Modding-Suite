Zanzarah Enemy Editor v0.1
==========================

Что умеет:
- читать _fb0x05.fbs;
- показывать NPC и их команды фей W.<fairy>.<slot>.<level>;
- менять до 5 фей и их уровни;
- читать SCN, связывать Scene type=4 с Trigger type=2 и UID из _fb0x05;
- показывать NPC на простой X/Z-схеме;
- менять X/Y/Z и направление NPC;
- добавлять новое размещение существующего NPC;
- удалять размещение;
- сохранять изменённые _fb0x05.fbs и SCN через браузер.

Запуск:
1. Откройте index.html в Chrome или Edge.
2. Нажмите «Открыть папку игры».
3. Выберите папку, внутри которой находятся _fb0x05.fbs и SCN-файлы.
   Можно выбрать более высокую папку: браузер прочитает вложенные файлы.
4. Выберите сцену слева.

Сохранение:
Браузер скачивает изменённый файл. Сделайте резервную копию оригинала и замените им файл игры вручную.

ВАЖНО:
- В v0.1 добавление создаёт ещё одно размещение уже существующей записи NPC из _fb0x05.
  Поэтому игровые события/состояние могут быть общими с оригиналом. Независимое клонирование записи NPC будет отдельной функцией следующей версии.
- Схема в центре — не 3D-геометрия уровня, а проекция координат X/Z найденных NPC.
- Для нового NPC на сцене без других NPC используются типичные поля Trigger type=2; на сцене с NPC новый Trigger наследует безопасные служебные поля выбранного/первого NPC.
- Всегда храните оригинальные игровые файлы.
