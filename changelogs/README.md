# Version changelogs

This directory contains the detailed per-version changelog files preserved from historical ZMS builds.

The **single canonical master changelog** is [`../CHANGELOG.md`](../CHANGELOG.md). It must always describe the newest project state and include the accumulated release history.

Per-version files in this directory are archival release notes and should not be treated as separate master changelogs.

For Git tags and historical build status, see [`../docs/releases/HISTORY.md`](../docs/releases/HISTORY.md).
