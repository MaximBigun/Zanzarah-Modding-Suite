Zanzarah World Editor v0.8.0 EXP

Кастомные wild encounter pools:
- добавлен экспериментальный патчер zanthp.exe;
- оригинальные Pool 0..33 остаются без изменений;
- добавляются новые Pool 34..45;
- каждый кастомный пул: до 8 weighted slots;
- вероятность задаётся весами (повтором fairy ID в слотах);
- levelParam M редактируется отдельно, рядом показывается вычисляемый диапазон уровня;
- редактор умеет читать свои уже пропатченные EXE и восстанавливать конфигурацию custom pools;
- активированные custom pools появляются в обычном списке «Дикие феи» и могут быть записаны в Trigger.ii4 SCN.

Технически:
- entry функции 0x00476102 перенаправляется в code cave в секции _rwcseg;
- для ID 0..33 управление возвращается в оригинальный jump-table 0x00476118;
- для ID 34..45 используется новая jump-table и generated stubs;
- _rwcseg VirtualSize расширяется в пределах уже существующего RawSize; секции EXE не перемещаются.

ВАЖНО: это первая экспериментальная версия custom-pool patcher. Статическая структура патча и round-trip тесты проверены, но запуск кастомного Pool 34+ в самой игре должен быть подтверждён игровым тестом.
